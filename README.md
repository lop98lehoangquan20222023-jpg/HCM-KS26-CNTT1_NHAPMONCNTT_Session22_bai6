# Viết prompt cho AI:
```
Vai trò:tôi là một sinh viên cntt 
Bối cảnh và vấn đề:Tôi đang dùng terminal để đẩy code lên github thì gặp lỗi:"error: open(".git/FETCH_HEAD"): Permission denied".
Yêu cầu:Hãy giải thích nguyên nhân lỗi và hướng dẫn cách khắc phục
```
# Xử lý bằng quyền Run as Administrator & Lưu ý chụp ảnh màn hình:
- Mở Command Prompt hoặc PowerShell bằng cách nhấp chuột phải chọn Run as Administrator.
- Chụp ảnh chuyên nghiệp:
1. Khoanh vùng lỗi: Dùng khung màu đỏ đánh dấu vào dòng thông báo lỗi
2. Bảo mật thông tin: Dùng công cụ chỉnh sửa ảnh để che đi các thông tin nhạy cảm như tên tài khoản cá nhân
# Soạn tin nhắn nhờ giảng viên hỗ trợ:
```
Dạ em chào thầy/cô,em tên là ... học lớp ... em đang dùng terminal để đẩy code lên github thì gặp lỗi "error: open(".git/FETCH_HEAD"): Permission denied".Em đã tìm kiếm trên AI và Stackoverflow nhưng vẫn chưa sửa được.Em nhờ thầy/cô giúp em với được không ạ (gửi kèm hình ảnh lỗi đã khoanh vùng chỗ có lỗi).
```
